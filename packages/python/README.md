# iragt

Official Python CLI for IRAGT Secure Tunnels.

## Installation

```bash
pip install iragt
```

## Quick Start

Connect to your tunnel with your token:

```bash
iragt connect YOUR_TOKEN
```

## Features
- **Zero-Flag Multi-Port Forwarding**: Automatically forwards all local ports configured in your web dashboard.
- **Fast & Encrypted**: Powered by SSH-multiplexed secure tunnels.
- **Custom Domains**: Automatic routing for all your attached domains.
