Frequently Asked Questions

Quick answers to common questions.

Do I need to install any software?
No. Any modern operating system already includes an SSH client. Windows 10+, macOS, and Linux all work out of the box.
Is my tunnel URL permanent?
On the Free plan URLs are random per session. Pro and Enterprise plans keep the same subdomain for every token you create.
Can I use my own domain?
Yes. Pro includes one custom domain; Enterprise includes unlimited custom domains plus Cloudflare-managed SSL.
The command uses SSH. Doesn't it open up my computer to threats?
No. Only the specific local port you choose is forwarded. Token authentication and SSH encryption protect the connection end-to-end.
The URL changes after I restart the tunnel.
Upgrade to Pro for persistent subdomains. Each token keeps the same URL across reconnects.
Does it work on all platforms?
Yes — Linux, Windows, macOS, and Android are all supported through the built-in SSH client.
