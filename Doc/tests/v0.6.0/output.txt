## Changes
1. Migration 0015: `plans` table (id/name/prices/tagline/features/cta/popular/active/
   sort) seeded with free/pro/enterprise matching the previous static landing.
2. Migration 0016: `invoices` table (invoice_no INV-YYYYMM-XXXXXXXX, payment_id

   (name/prices/tagline/features/cta/popular/active/sort — audited).

6. UI: admin 💎 Plans editor (edit modal: name/INR/USD/tagline/features/CTA;

   + void + view/print). User dashboard subscription page gained 🧾 My Invoices
   with print links. Landing pricing now renders from GET /api/v1/plans.
