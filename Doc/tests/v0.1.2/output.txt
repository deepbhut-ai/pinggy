Trigger: server log showed `GET /api/v1/tunnels/history?limit=500 → 200`, a route
missing from Doc/functions.md + Doc/process-flow.md (only 3 of 7 tunnels routes were
documented). Root cause of the drift: the original grep pattern
`@router\.(get|post|put|delete|patch)\("[^"]*"\)` only matches decorators where the
path string is the ONLY argument — routes with `response_model=`/`status_code=` args
were silently missed (`/my`, `""`, `/history`, `DELETE /{subdomain}`).
