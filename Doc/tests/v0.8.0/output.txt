# v0.8.0 — Tunnel security options + bandwidth widget (Track 2 + 8) — 2026-08-29

## Changes
1. Migration 0018: tokens += basic_auth_user/pass, ip_whitelist, bearer_key,
   https_only (all NULL/FALSE by default — zero behavior change until enabled).
2. proxy.py: `_get_token_security` (loads per-token settings; returns None when
   unconfigured = zero-overhead passthrough) + `_check_security` enforcing:
   - Basic auth (constant-time compare, WWW-Authenticate challenge)
   - IP whitelist (exact IPs + CIDR, CF/X-Real-IP/XFF-aware client IP)
   - Bearer/API-key (X-Api-Key or Authorization: Bearer)
   - HTTPS-only (also honors x-forwarded-proto behind a proxy)
   Blocked requests are counted + logged to the user's SSH terminal.
3. ssh_server/tunnel_registry: TunnelSession now carries the authenticating
   `token` (required for the proxy lookup; fixed mid-test — initially security
   was silently skipped because the field was missing).
4. tokens.py PUT /tokens/{id}: accepts the 5 security fields ("auto" generates a
   bearer key; empty string clears); TokenOut.security exposes a masked view
   (passwords never returned; bearer shown as ***set***); all changes audited.
5. dashboard edit-token modal: 🔒 Security section (basic auth user/pass,
   IP whitelist, API key, HTTPS-only toggle) — loads current masked state.
6. Subscription page: Bandwidth Usage progress widget (lifetime transfer,
   "no cap" messaging).
