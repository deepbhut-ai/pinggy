# v0.7.0 — Command Builder 2.0 (Track 1) — 2026-08-29

Per competitive analysis roadmap (Doc/reports/pinggy-competitive-analysis.md).

## Changes
1. Migration 0017: `tunnel_configs` (saved builder configs per user, JSON blob).
2. `configs.py` router: GET/POST/PUT/DELETE /configs (owner-scoped).
3. GET /tunnels/qr?text= → SVG QR code (qrcode pkg; authed; 512-char cap).
4. dashboard.html Configure page → **Builder 2.0**:
   - **16 app presets** (Django/Flask/Jupyter/Node/React-Vite/Next/Vue/Laravel/
     WordPress/Nginx/Apache/MySQL/PostgreSQL/MongoDB/Redis/custom) — selecting one
     fills the local address.
   - **Download buttons**: .sh, .bat, .command scripts (auto-reconnect wraps the ssh
     command in a reconnect loop when the toggle is on).
   - **SSH / Docker tabs** (Docker emits alpine/openssh-client one-liner).
   - **QR Code** button renders the tunnel URL as a scannable SVG.
   - **Save / Load saved configurations** (persisted via /configs API).
   - Auto-Reconnect toggle (affects downloaded scripts).
