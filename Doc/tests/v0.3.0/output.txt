# v0.3.0 — Phase B: per-token traffic + daily/monthly insights — 2026-08-29

## Changes
1. **Job 4 — per-token traffic**: migration 0011 (`tunnels.token` + index + backfill
   from users.tunnel_token); ssh_server `_setup_tunnel` records the SSH-auth token;
   `TokenOut`/`AdminTokenOut` += total_requests/total_bytes/active_tunnels via
   `_token_traffic()` aggregation; admin All Tokens table += Requests/Data/Active
   columns + summary cards; user dashboard token table += same columns.
2. **Bug fix (required for Job 4)**: `increment_request_count` previously updated ONLY
   the in-memory registry — tunnels table counters stayed 0 forever. Now writes through
   to the DB (best-effort; never breaks the proxied request).
3. **Job 7 — insights**: `GET /api/v1/analytics/overview?days=7..180` (daily series via
   generate_series LEFT JOINs, 12-month monthly series, today/this-month summary);
   admin dashboard "📈 Insights (Daily / Monthly)" card — summary stat cards, Day/Month
   tabs, range cycler (30/60/90d), dependency-free CSS bar charts.
