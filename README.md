# pinggy — SSH Tunnel Service

A **pinggy.io / ngrok alternative** built with FastAPI + PostgreSQL + asyncssh.
Exposes local development servers to the internet via SSH reverse tunnels.

## 🚀 Quick Start

### Production (One Command)

On a fresh Ubuntu 22.04+ server:

```bash
git clone <your-repo-url> /opt/pinggy && cd /opt/pinggy && bash setup.sh
```

This will:
1. Install Docker + Docker Compose
2. Create `.env` with secure JWT secret
3. Build and start all containers (PostgreSQL, FastAPI, nginx)
4. Create admin user (`admin` / `admin`)

### Production (Manual)

```bash
# Clone
git clone <your-repo-url> /opt/pinggy && cd /opt/pinggy

# Configure
cp .env.docker .env
nano .env  # Set DOMAIN, JWT_SECRET, payment keys

# Build & start (production compose file)
docker compose -f docker-compose.prod.yml up -d

# Create admin user
docker compose -f docker-compose.prod.yml exec app python -c "
import psycopg, secrets
from passlib.hash import bcrypt
conn = psycopg.connect('host=db dbname=pinggy user=pinggy password=pinggy_secret')
cur = conn.cursor()
cur.execute('SELECT id FROM users WHERE email = %s', ('admin',))
if not cur.fetchone():
    token = secrets.token_hex(8)
    cur.execute('INSERT INTO users (email, password_hash, full_name, role, tunnel_token, plan) VALUES (%s, %s, %s, %s, %s, %s)', ('admin', bcrypt.hash('admin'), 'Default Admin', 'admin', token, 'free'))
    conn.commit()
    print('Admin created: admin / admin')
cur.close()
conn.close()
"
```

### Local Development

```bash
# Clone
git clone <your-repo-url> pinggy && cd pinggy

# Configure
cp .env.docker .env
# Edit .env: set DOMAIN=localhost, DB_PASS=pinggy_secret

# Start (local dev compose — exposes DB port for debugging)
docker compose up -d

# App: http://localhost:8000
# DB: localhost:5432
# SSH: localhost:2222
```

## 🏗️ Architecture

```
                    Internet
                       │
              ┌────────┴────────┐
              │   Cloudflare     │
              │  (SSL Flexible)  │
              └────────┬────────┘
                       │ :80
              ┌────────┴────────┐
              │     nginx        │
              │  (port 80 only)  │
              └────────┬────────┘
                       │
              ┌────────┴────────┐
              │   FastAPI app    │
              │   (port 8000)    │
              │   + SSH server   │
              │   (port 2222)    │
              └────────┬────────┘
                       │
              ┌────────┴────────┐
              │   PostgreSQL     │
              │   (port 5432)   │
              └─────────────────┘

  Cloudflare Proxied (orange) → domain.com      → :80  (HTTPS via CF)
  Cloudflare DNS only (grey)  → ssh.domain.com  → :2222 (SSH direct)
```

### Docker Services

| Service | Container | Port | Purpose |
|---------|-----------|------|---------|
| nginx | `pinggy-nginx` | 80 | Reverse proxy → app |
| app | `pinggy-app` | 8000, 2222 | FastAPI + SSH tunnel server |
| db | `pinggy-db` | 5432 | PostgreSQL database |

## 🌐 DNS Setup

In your Cloudflare dashboard:

| Record | Type | Value | Proxy |
|--------|------|-------|-------|
| `yourdomain.com` | A | `SERVER_IP` | **Proxied** (orange) |
| `ssh.yourdomain.com` | A | `SERVER_IP` | **DNS only** (grey) |

Then: **SSL/TLS → Flexible** mode.

> The main domain must be proxied (orange) for HTTPS to work.
> The SSH subdomain must be DNS-only (grey) — SSH can't go through Cloudflare's HTTP proxy.

## ⚙️ Configuration

Edit `.env` (created from `.env.docker` template):

```env
# Domain
DOMAIN=iraglobaltech.com

# Database
DB_USER=pinggy
DB_PASS=pinggy_secret
DB_NAME=pinggy

# JWT (auto-generated by setup.sh)
JWT_SECRET=your-random-hex-string

# SSH port (must be exposed directly)
SSH_PORT=2222

# Payments (leave empty to disable)
STRIPE_SECRET_KEY=
STRIPE_ENABLED=false
PAYPAL_CLIENT_ID=
PAYPAL_ENABLED=false
NOWPAYMENTS_API_KEY=
NOWPAYMENTS_ENABLED=false
```

After editing `.env`, restart:
```bash
# Production
docker compose -f docker-compose.prod.yml restart

# Local dev
docker compose restart
```

## 📖 Usage

### Start a Tunnel

```bash
ssh -p 2222 -R0:127.0.0.1:8080 -o StrictHostKeyChecking=no -o ServerAliveInterval=30 YOUR_TOKEN@ssh.yourdomain.com
```

Replace `YOUR_TOKEN` with your token from the dashboard, and `8080` with your local service port.

## 🛠️ Management Commands

### Production (`docker-compose.prod.yml`)

```bash
# View logs
docker compose -f docker-compose.prod.yml logs -f
docker compose -f docker-compose.prod.yml logs -f app    # App only
docker compose -f docker-compose.prod.yml logs -f db     # Database only

# Restart
docker compose -f docker-compose.prod.yml restart

# Stop / Start
docker compose -f docker-compose.prod.yml down
docker compose -f docker-compose.prod.yml up -d

# Rebuild after code changes
docker compose -f docker-compose.prod.yml build && docker compose -f docker-compose.prod.yml up -d

# Check status
docker compose -f docker-compose.prod.yml ps

# Run database migrations
docker compose -f docker-compose.prod.yml exec app alembic upgrade head

# Access PostgreSQL
docker compose -f docker-compose.prod.yml exec db psql -U pinggy -d pinggy
```

### Local Development (`docker-compose.yml`)

```bash
docker compose up -d          # Start
docker compose logs -f        # Logs
docker compose restart        # Restart
docker compose down           # Stop
docker compose ps             # Status
```

## 🧪 Tech Stack

- **Backend**: FastAPI 0.115 + uvicorn
- **Database**: PostgreSQL 16 + psycopg3 (async)
- **SSH Server**: asyncssh 2.17
- **Auth**: JWT (PyJWT) + bcrypt
- **Payments**: Stripe, PayPal, NowPayments (via httpx REST)
- **Proxy**: nginx + Cloudflare Flexible SSL
- **Frontend**: Vanilla HTML/JS (no framework)
- **Migrations**: Alembic
- **Container**: Docker + Docker Compose
